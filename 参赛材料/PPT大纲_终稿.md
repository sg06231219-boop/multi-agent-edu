## 第4页：系统架构（核心页）

**标题：** 七智能体协同决策流水线

```
用户输入 → ①诊断 → ②知识生成 → ③审核辩论(2轮) → ④实操指南
→ ⑤分阶测试 → ⑥动态迭代 → ⑦苏格拉底导学 → 输出学习方案
```

**关键设计：**
- 顺序流水线 + 辩论循环 + 反馈闭环
- SSE实时可视化：用户全程感知AI协同过程
- 每Agent独立Prompt + Fallback降级策略

## 第5页：多智能体协同决策机制（重点）

**标题：** 四层协同决策机制

| 协同层 | 机制 | 说明 |
|--------|------|------|
| 顺序流水线 | 7Agent按序执行 | 前一Agent输出自动传入下一Agent |
| 辩论式协同 | 生成↔审核2轮辩论 | 角色对立，强制最少2轮 |
| 反馈闭环 | 测试→迭代→再生成 | 掌握概率<70%触发补充内容 |
| 实时可视化 | SSE推送 | 全程可见，增强可信度 |

**辩论机制关键参数：**
- `min_rounds=2`（强制至少2轮）
- `hallucination_score<20`才能通过
- 第1轮至少找3个问题，第2轮检查是否真正修正

## 第6页：幻觉防控方案（重点）

**标题：** 四层防线将幻觉率从12.3%降至3.0%

```
第一层：知识库锚定 — TF-IDF检索注入，以知识库为参考锚点
第二层：双视角审核 — 专业性 + 逻辑性交叉验证
第三层：强制多轮辩论 — 最少2轮，第1轮至少找3个问题
第四层：人工审核预留 — 2轮后仍不达标标记"需人工审核"
```

**消融实验数据：**
| 配置 | 幻觉率 |
|------|--------|
| 无审核 | 12.3% |
| 1轮审核 | 6.8% |
| 2轮辩论（本系统） | **3.0%** |

**配图建议：** 四层防线漏斗图（12.3% → 6.8% → 3.0%）

## 第7页：知识个性化生成流程（重点）

**标题：** 三层面个性化：内容深度 × 测试难度 × 导学策略

**流程：**
1. 诊断Agent → 分析知识盲区，确定focus_topic
2. 知识生成Agent → TF-IDF检索+水平适配生成内容
3. 分阶测试Agent → 入门/基础/进阶三档匹配
4. 动态迭代Agent → 测试结果驱动难度调整
5. 苏格拉底导学Agent → 个性化追问节点

**个性化效果：**
- 初学者：通俗类比 + 基础语法 + 入门测试
- 高级用户：底层原理 + 性能优化 + 进阶测试

## 第9页：创新点1 — 辩论式审核

**标题：** 创新点1：双视角辩论式审核机制

**对比：**
- 传统方法：单Agent自检，错误检测率<30%
- 本系统：生成Agent vs 审核Agent角色对立，双视角交叉验证

**双视角：**
- 专业性：术语准确？概念混淆？代码正确？过时？
- 逻辑性：论证自洽？因果成立？结论过度推断？

**效果：** 幻觉率12.3% → 3.0%，降幅75.6%

**配图建议：** 生成Agent vs 审核Agent对抗图

## 第10页：创新点2 — 动态迭代闭环

**标题：** 创新点2：动态迭代在线优化

**机制：**
```
测试评估 → 掌握概率计算 → 薄弱环节识别 → 补充内容生成 → 再测试
```

**三档策略：**
- 正确率<60% → 降维解释（difficulty_shift: -2）
- 60-80% → 定点突破（difficulty_shift: 0）
- >80% → 进阶挑战（difficulty_shift: +2）

**核心价值：** 系统"越用越好"，内容随反馈持续优化
